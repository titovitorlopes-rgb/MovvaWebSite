# MOVVA

Website oficial da MOVVA - Criação de Sites, Landing Pages e E-commerce de Alta Performance.

## Páginas
- `index.html`: Página inicial com apresentação e seção Sobre com vídeo background
- `servicos.html`: Nossos serviços e detalhes das soluções
- `precos.html`: Planos e preços interativos

## Tecnologias
- HTML5, CSS3 moderno, JavaScript vanilla (animações e interações puras)
